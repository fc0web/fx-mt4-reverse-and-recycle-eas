# RevWhole EA — パラメータ詳細

監視対象 EA のポジションを **反対方向**にコピーする補助 EA。

## 用途例

- 既存の自動売買 EA が「負ける期間が長い」 と判断する場合、 RevWhole を併用して反対ポジションを建て、 トータルでヘッジ
- 「自分の戦略の逆が儲かる」 仮説を検証する (ペーパー / デモ)
- 複数 EA のポジションを集合的に逆張りする

## 重要 (用途上の特性)

- 監視対象 EA が **儲かっている期間** は RevWhole は **損失を出します** (鏡像関係)
- 監視対象 EA が **負けている期間** は RevWhole は **利益を出します**
- 結局、 元 EA のリスクと収益カーブの **逆 (時間遅れあり)** を持つことになる

## パラメータ一覧

### 基本

| パラメータ | 既定 | 説明 |
|---|---|---|
| `Mnumber` | 20240710 | 当 EA 自身のマジックナンバー |
| `Mnunber_identification` | "" | 監視対象マジックナンバー (カンマ区切り、 空欄で MT4 全体を監視) |

### ポジション設定 (`Position`)

| パラメータ | 既定 | 説明 |
|---|---|---|
| `stopL` | 0 | 反転ポジションの損切り (Point、 0 で OFF) |
| `takeP` | 0 | 反転ポジションの利確 (Point、 0 で OFF) |
| `lotBairitu` | 1.0 | ロット倍率 (元ポジションの何倍で反転するか) |

★ `lotBairitu` を `0.5` 等にすれば**部分ヘッジ**、 `2.0` 等にすれば**過剰反張り** (リスク増)。

### 決済設定 (`_eXiT`)

| パラメータ | 既定 | 説明 |
|---|---|---|
| `exitLogic` | 1 | 決済対象: 0=MT4 全体 / 1=このEAのポジションのみ |
| `takeP_EN` | 0 | 利確ターゲット金額 (口座通貨、 0 で OFF) |
| `stopL_EN` | 0 | 損切りターゲット金額 (マイナスで入力、 0 で OFF) |
| `useExitRendo` | false | 決済をコピー元ポジションと連動 (元が閉じたら反転も閉じる) |

### その他

| パラメータ | 既定 | 説明 |
|---|---|---|
| `useSpreadSliPLimit` | true | スプレッド & スリッページ制限 |
| `Max_spread` | 50 | 最大スプレッド (Point) |
| `Slippage` | 5 | 許容スリッページ (Point) |

# RecirCycle EA — パラメータ詳細

独立してエントリー → ドテン → 循環する EA。 追い上げ機能を持つ。

## 動作フロー (作者コメント原文より)

1. 起動時、 設定方向 (Buy / Sell / 両建て) で成り行きエントリー (初手 TP/SL 付き)
2. TP に到達 → 利益確定。 `(0)` に戻る (再エントリー)
3. SL に到達 → 損切り。 **ドテン (反対方向に建て直し)** に進む
4. ドテンポジションは独自の TP/SL を持つ
5. ドテンの結果に応じて再循環

「**勝ち追い上げ**」 と 「**負け追い上げ**」 の両方を ON/OFF 可能:
- 勝ち追い上げ = 含み益が出たら同方向に積み増し (ピラミッディング)
- **負け追い上げ = 含み損が深まったら同方向に積み増し (★マーチンゲール、 高リスク)**

## ★ 重要な技術要件

- **`wininet.dll` を import** しています。 MT4 のチャートに EA を載せる際、 **「DLL の使用を許可する」 にチェック必須**。
- **LINE 通知** を使う場合、 LINE Notify の Access Token が必要。
- **メール通知** を使う場合、 MT4 の `ツール` → `オプション` → `メール` で設定が必要。

## LINE 通知の設定方法 (RecirCycle のみ)

1. LINE Notify (https://notify-bot.line.me/) でアクセストークンを取得 (note: LINE Notify は今後仕様変更の可能性あり)
2. MT4 EA パラメータ `AccessToken` にトークンをペースト
3. チャートに EA を載せる際の「**DLL の使用を許可する**」 にチェック
4. `alertsLINE = true` に設定

★ **アクセストークンは個人情報相当**です。 設定後はパラメータ画面のスクショ等で漏らさないようご注意下さい。

★ LINE Notify のサービスは今後変更/終了の可能性があります。 動作しなくなった場合は LINE 側仕様を確認して下さい。

---

## メール通知の設定方法 (RecirCycle のみ)

1. MT4 メニュー: `ツール` → `オプション` → `メール` タブ
2. SMTP サーバー、 ログイン、 パスワード、 From、 To を設定
3. EA パラメータ `alertsEmail = true`

## よくある質問 (FAQ)

### Q1. RevWhole と RecirCycle、 どちらを使うべき?

A. 用途次第:
- **既存 EA のヘッジ / 鏡像戦略を試したい** → RevWhole
- **独立した循環戦略を動かしたい** (ドテン + 追い上げ) → RecirCycle

両方を同時に動かすこともできますが、 ロジックが衝突しないよう **異なるマジックナンバー** を割り当てて下さい。

### Q2. 初期設定のままで使っていい?

A. **推奨しません。** 特に RecirCycle のデフォルト (負け追い上げ + 勝ち追い上げ ON + マーチン倍率) は高リスクです。 最初は:
- `useOiage_make = false` (負け追い上げ OFF)
- 最小ロット (0.01)
- デモ口座 で挙動確認

### Q3. 推奨通貨ペア / 時間足は?

A. **本リポジトリでは推奨しません。** 投資助言に近づくため honest に何も推奨しません。

### Q4. 過去のバックテスト結果や勝率を見せてほしい

A. **本リポジトリでは公開しません。** ご自身で MT4 ストラテジーテスターを使って検証して下さい。

### Q5. 損失が出ました。 補償してもらえますか?

A. **補償しません。** MIT ライセンス「AS IS」 配布です。 LICENSE をお読み下さい。

### Q6. 商用利用してもいいですか?

A. はい、 MIT なので可。 ただし「○○式 EA で稼げます」 等の **断定的性能表現** で配布する場合、 配布者ご自身が景表法・金商法等の規制を負います。

### Q7. RecirCycle で「DLL の使用を許可する」 にチェックを入れたくない

A. その場合、 LINE 通知機能は使えません (`alertsLINE = false` に設定)。 EA 本体の取引機能は動作します。

### Q8. LINE Notify が動かなくなりました

A. LINE 側の仕様変更の可能性があります。 LINE Notify 公式情報をご確認下さい。 本 EA は LINE 仕様の変更に追従しません。
